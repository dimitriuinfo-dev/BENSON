# Heed “Benson” model provenance for the 2026-09-30 recovery build

- Wake runtime reference: `AndreiBulzan/heed-wakeword`, source commit `643a93c1e6702640c515475500f2e2653bd7d621`, release 0.1.4, Apache-2.0. The Android detector/preprocessor in this repository is BENSON integration code; the ONNX Runtime Android dependency is `com.microsoft.onnxruntime:onnxruntime-android:1.24.3`.
- Model artifact: locally trained synthetic-only “Benson” candidate, packaged as `heed_candidate.onnx` with `heed_candidate.json` and `heed_filter_coeffs.json`. The ONNX is 110,937 bytes; SHA-256 `57E18401D6C146907EE669B17B82C79FED1C2D94C593FF949F6F36FE591B4779`. Manifest SHA-256 `CB55D04C5AD8318C8579AE0E03AA0F7DC3BFC863465B1303DC678F2A5F257333`; coefficient SHA-256 `D45ACB3D88BBC9D55A8D9E74CE01E9ED325800B0967ED9158A20AF4968578AED`.
- Training provenance retained locally (not in Git): `.benson-training/heed-benson-synth/model.json` and `config.json`; generated synthetic speech used Romanian `ro_RO-mihai` and German `de_DE-thorsten` Piper voices, and negative/distractor phrases. The associated voice model cards identify their source datasets as CC0 (`NabuCasa/voice-datasets` and `Thorsten-Voice`). No owner recordings were used, and no audio examples or voice binaries are included in this checkpoint. The user-specific training tree and cached audio remain local and excluded.
- Heed upstream runtime/source notice and Apache-2.0 license are retained beside the Android module. Attribution: Heed Wake Word, Copyright 2026 Andrei Bulzan, https://github.com/AndreiBulzan/heed-wakeword.
- The packaged model is a candidate, not an Alexa-grade claim: local synthetic evaluation was mixed (3/3 positives and 0/9 distractors across one held-out Piper set; separate emotional German synthetic set reached 43.2% TPR at zero false positives). Do not treat those small synthetic checks as field false-accept evidence.
- The artifact and its exact hash are sufficient to reproduce the recorded APK build from the committed app source/dependency versions. The local training samples/cache are intentionally not distributed, so retraining the same weights from scratch is not promised by this checkpoint. Before broader redistribution, separately audit the exact Piper voice-weight licenses; the retained model cards state dataset licenses, not necessarily every generated model artifact's license.
